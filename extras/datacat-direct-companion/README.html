Datacat Direct Import

One-time Chrome setup. After this, select a card in Character Library and click Import. Your signed-in Datacat tab opens, downloads the official card, and returns it automatically. Complete Datacat's human check there when requested.

  1. In Chrome, open chrome://extensions and enable Developer mode.
  2. Click Load unpacked and select extras/datacat-direct-companion inside your SillyTavern Character Library extension folder.
  3. Reload Character Library and click Import again.

The companion runs only on datacat.run and the local Character Library page on localhost or 127.0.0.1. It reads no passwords, cookies, account tokens, or browsing history. It has no file access or downloads permission. Pending requests use temporary browser-session storage, so verification can outlast Chrome's background-worker suspension.

cl-helper remains the first download attempt. This companion handles exports that Datacat requires your browser to verify. Creator restrictions and normal verification remain in place. Character Library checks the returned PNG and selected identity before importing it. Public Source lorebooks are enriched by the existing import path when Datacat's PNG omits them.

Remove or disable this companion from Chrome's Extensions page whenever you want.
